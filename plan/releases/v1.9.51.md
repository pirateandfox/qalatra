## Highlights

**Qalatra Connect now has a complete account gate for the hosted web and native apps.**

- Assigned Connect and included Cloud seats unlock the clients across organization memberships.
  Multiple plans no longer hide a valid seat. Account login supports two-factor verification.
- Access is checked every minute and when returning to the app. Revoked seats lock access on the
  next check; temporary account-service outages have a five-minute grace after verification.
- Mobile 0.3.0 is login-only, with access refresh and sign-out. Corrected an invalid SecureStore
  key that prevented saving/loading account credentials. Backend changes cannot bypass login.
- Hosted web builds always enable the account gate. Added the deployment container for
  app.qalatra.com. The free desktop continues to work without a Connect subscription.
- The account portal adds audited, admin-only complimentary Connect seats without Stripe charges
  or Cloud provisioning. Normal organization users continue to buy and assign licenses.
- Updated pipeline agent instructions for FlightDesk-connected work instead of Linear status writes.
