## Highlights

**A finished agent turn now always reaches FlightDesk, even across network failures and restarts.**

- Before, a DONE/FAILED report that failed to send was logged and lost, or retried only while
  FlightDesk still listed the dispatch. The turn then stayed RUNNING in FlightDesk although the
  work had ended.
- Each report is now stored in a new `external_reports` table and retried every 30-second tick,
  backing off to 15 minutes, until FlightDesk confirms it. Stored reports survive a server restart.
- The job's final database write records that a report is owed, in the same transaction, so a
  crash before the report is built still delivers it; it is rebuilt from the job.
- Restart-orphan reports and session-op results use the same path.
- A report is dropped only when FlightDesk says the dispatch doesn't exist, after 10 rejections,
  or after a week; each case is logged. The integrations status shows how many are pending.
