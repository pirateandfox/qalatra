# Qalatra 1.9.7

- Added an explicit Settings -> Instances -> Startup Default selector. Existing remote active-instance selections migrate into this default automatically.
- Added a setting to hide Local Server from the header instance switcher while keeping it available in Settings.
- Changed header instance switches to apply to the current app session, with restart selection controlled by Startup Default.
- Reworked the slide-up document Terminal/Chat panel to use the same server-backed tmux/WebSocket terminal transport as the Terminals view.
- Document Terminal now opens in the document folder on the active Qalatra server; document Chat starts the configured agent command from that folder.
