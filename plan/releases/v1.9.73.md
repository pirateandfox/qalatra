## Highlights

**Task notes can no longer stop an agent job from starting.**

- A new job's prompt included every note on the task. The prompt reaches the agent CLI as a single
  argument, and Linux limits one argument to 131,072 bytes, so a long-lived task that collected a
  note on every run eventually failed at launch with `E2BIG` (reported from a box at 134,881 bytes).
- The prompt for a new job is now kept under 120 KB. The newest notes are included; older ones are
  replaced by a line telling the agent to read them with `get_task_notes`. A description too large
  to fit is shortened, with a pointer to `get_task`, and room is always left for the notes. Your new
  message is always included in full.
- If a prompt is still over the limit (for example, one an orchestrator sent verbatim), the job now
  fails as `launch_failed` with the prompt's size in the result, not a bare `E2BIG`.
- Resumed sessions already sent only the new turn and are unchanged.
