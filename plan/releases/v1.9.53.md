## Highlights

**FlightDesk work stays out of your to-do list.**

- Every task Qalatra creates or binds for a FlightDesk dispatch is now a coding task, and
  existing ones are corrected at startup. They appear only in the Coding view.
- The priority/today view, inbox, morning and afternoon briefings, end-of-day triage, stale
  and backlog reviews, overdue lists, and `get_todays_tasks` also exclude any task an
  orchestrator drives, so a mis-typed task can never leak in again.

**FlightDesk-bound tasks now close themselves.**

- A task closes once its FlightDesk task is DONE, archived, or deleted and none of its
  jobs is queued or running. Qalatra checks when a job ends and every 15 minutes; the first
  check after startup clears tasks that had already piled up.
- A closing note is added to the task. Nothing is sent back to FlightDesk, and
  `complete_task` no longer queues a sync entry for orchestrated tasks.
- If a finished FlightDesk task receives a new dispatch, the same Qalatra task reopens, so
  one FlightDesk task always maps to one Qalatra task.
