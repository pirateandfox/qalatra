## Highlights

**Native Claude permission requests now reach FlightDesk through session-state reports.**

- Preserve the pending-approval flag and complete approval card, even when a transcript is
  unavailable. A session waiting for permission never counts as idle.
- Report an explicit cleared card when the session resumes so FlightDesk can reconcile a
  permission answered directly in Claude. This requires the matching FlightDesk support;
  Qalatra reports the state and does not grant permissions automatically.

**Connecting clients and managing access is clearer.**

- Hosted web users without a server get a guided setup screen with instructions for finding
  the server URL and creating an access token. Connections are tested before being saved.
- The mobile companion has matching setup guidance, clearer credential labels, and help
  when adding another server. These mobile changes are also available through the 0.3.0
  Expo update; this desktop release does not change the mobile binary version.
- Active and expired tokens remain visible in Settings → Instances. Revoked tokens move
  into a collapsed history with a count and revocation dates.
- Account-screen actions have consistent spacing on desktop-sized browsers and phones.
  The hosted access screen links directly to the Connect portal.
- The website now offers a choice of web app or account portal at login and preserves
  portal destinations through sign-in. The hosted app is live at app.qalatra.com, and
  the renewed iOS 0.3.0 (10) beta is available in TestFlight.
- Qalatra Desktop remains free and open source, with no account or subscription gate.

## Verification

- Full pre-publish validation: dependency audits, shared/mobile type checks, account

- iOS and Android JavaScript bundle exports for the mobile setup guidance.
- Release CI repeats validation before building and publishing signed/notarized macOS
