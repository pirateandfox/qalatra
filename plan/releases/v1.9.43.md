## Highlights

**Detail reads no longer carry the plan or the log by default.** A per-box usage report attributed
roughly half of agent spend to Qalatra tool results: a pipeline orchestrator polls hourly, and every
pass called `get_task` (full plan text), `list_agent_jobs`, and `get_agent_job` (the complete job
output), each of which then sat in the session for the rest of its life. The earlier `fields` work
covered the list tools; the two detail reads still returned everything.

- `get_task` now returns every column except `description`, `ai_context`, and `notes`, reporting
  the omitted sizes under `omitted` so a caller can tell a 10k plan from an empty one. It accepts
  the same `fields` projection as the other reads; `fields="description"` or `"*"` fetches the
  text. On the largest development task: 12,787 → 1,370 bytes.
- `get_agent_job` returns the last 2,000 characters of `result` with a visible
  `[…] N earlier characters trimmed` marker and a `result_length`, since the agent's summary and
  any error sit at the end. `result_chars` adjusts the tail; `0` or `fields="*"` returns it whole.
- `list_agent_jobs` pages 10 rather than 20 and takes a `status` filter (`"queued,running"`), so a
  poller asks for the jobs it cares about instead of paging through finished ones.

These are server-side defaults, so every agent on every box benefits without an agent change.

**Resumed agents receive only the new turn.** Claude and Codex restore the earlier transcript
provider-side when Qalatra resumes a session, but Qalatra also re-sent `job.prompt` — the task
description plus every task note — as the new turn when no explicit user message was set. Repeated
pipeline dispatches made that single argument grow until Linux could reject the spawn with `E2BIG`
before the CLI ran. Resumed jobs now send only the explicit user message, or a short instruction to
continue and inspect the live task. Fresh sessions still receive the complete initial prompt.

**Dependency advisories cleared.** Root, UI and mobile lockfiles were refreshed for the hono, js-yaml
and sharp advisories that landed since 1.9.42. `@react-navigation/core` 7.22.1 dropped its
`query-string` dependency, so the mobile audit's `decode-uri-component` exception is retired; the two
Metro `image-size` exceptions remain.

## Verification

New field-projection coverage exercises body omission, the `*` escape hatch, and result tailing;
worker coverage constructs a large accumulated prompt and proves neither explicit follow-ups nor
message-less resumed runs replay it. Handlers were run end-to-end against the development database
under the Electron runtime to confirm the measured payload sizes.
