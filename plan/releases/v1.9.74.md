## Highlights

**A recurring task's next occurrence no longer lands in the Inbox.**

- Completing or skipping an occurrence that was in the Inbox copied that flag to the next one, so
  next week's task appeared in the Inbox the moment this week's was done, a week early.
- The Inbox flag marks one occurrence for a decision, not the whole series, so new occurrences now
  always start outside the Inbox. Completing, skipping and the morning rollover all build the next
  occurrence the same way now, so they can't drift apart again.
- Notes, links, time estimate and agent settings still carry over to the next occurrence.
