# Qalatra 1.9.9

- Fixed dynamic Box Web apps that call root-absolute API paths like `fetch('/api/inbox')`.
- The proxied HTML now injects a small runtime shim that rewrites `fetch`, `XMLHttpRequest`, `EventSource`, and `navigator.sendBeacon` calls through the session-scoped `/api/box-web/proxy/<ticket>/...` URL.
- Bare Qalatra `/api/*` routes are still protected by bearer auth; the hotfix does not open a global unauthenticated API proxy.
