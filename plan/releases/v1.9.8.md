# Qalatra 1.9.8

- Added Box Web Apps: each saved remote instance can opt into one sidebar item that embeds that box's private `http://127.0.0.1:8080` web app.
- Added Settings -> Instances -> Box Web Apps controls with a per-box enable switch and configurable label.
- Added an authenticated Qalatra Server proxy at `/api/box-web/*`. The desktop client creates a short-lived session ticket using the existing bearer token, then loads the iframe without exposing the permanent token to the embedded page.
- Rewrites root-relative HTML links/assets and CSS `url(/...)` references so static dashboards and root tool pages can run behind the proxy.
- Documented the loopback-port setup and the optional relationship between public Cloudflare tool hostnames and private in-app embedding.
