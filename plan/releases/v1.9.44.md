## Highlights

**Agent commands can be an argv array, with no shell in between.** The 2026-09-01 incident that
delivered a one-word `Execute` prompt to a cloud session came from an `agent.config` command that
appended text inside the quotes around `'{description}'`: the substituted value closed the quote
early and the shell split the rest. The 2026-09-05 release added a launch warning for that shape,
but a warning is a tripwire over a hazard, not the removal of it. `command` may now be written as
an array. Each element is one argument, Qalatra starts the program directly, and `{title}`,
`{description}` and `{spec_file}` are spliced in verbatim — quotes, `$(…)`, backticks and newlines
all arrive exactly as written, because nothing is ever shell-parsed.

- Shell-string commands are unchanged. The fleet's dispatch configs rely on `$(…)`, `cd` and `&&`
  on purpose, and none of them has to move.
- Every run — both forms, and prompt-mode agents too — now receives `QALATRA_TITLE`,
  `QALATRA_DESCRIPTION`, `QALATRA_TASK_ID`, `QALATRA_JOB_ID` and, when the command references it,
  `QALATRA_SPEC_FILE` in its environment. A shell string that needs shell features can write
  `--prompt "$QALATRA_DESCRIPTION"` and the value never enters the command text. Title and
  description are capped at 64 KiB in the environment so a large plan cannot become an `E2BIG`
  spawn failure for an agent that never asked for it.
- The login shell still supplies the user's `PATH`, through `-i -l -c '"$0" "$@"'`, which hands
  the argv through untouched. Prompt-mode agents use the same wrapper (previously `${bin} "$@"`)
  and accept the array form, which also fixes base flags that contain spaces.
- Invalid arrays fail the job before spawn with a clear message. The unsafe-quote warning now names
  both alternatives, launch diagnostics report `template (argv)` / `template (shell)` / `prompt`
  and render argv commands shell-style so secret redaction still applies, and the agents table
  stores an array command as JSON.

**Release skill is shared.** `.agents/skills/publish-qalatra` is a symlink to the canonical
`.claude/skills` copy, and the release skill now records the curated notes file this workflow
requires.

## Verification

`scripts/test-worker-command-templates.mjs` covers argv substitution with hostile values, a missing
placeholder resolving to an empty argument, the ported-quotes warning, environment capping and
argv diagnostics redaction. Verified end-to-end through the real `zsh -i -l -c '"$0" "$@"'` wrapper
on macOS: a title containing `$(echo pwned)`, backticks and mixed quotes plus a multi-line
description reached a fake agent byte-for-byte in both argv and environment.
