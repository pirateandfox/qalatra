## Highlights

**First FlightDesk dispatch ran end to end on a real box.** On Shi, a `CUSTOM` dispatch was
acknowledged on the next 30-second tick, ran, ended its turn through the folder's own credential,
and was reported done — 58 seconds from request to completion, with no cloud session opened. The
broken-credential path was verified on the same box: rejected within one tick, surfaced as
`Unauthorized`, and recovered on the 5-minute retry with no restart.

- **Poll now bypasses the rejected-credential backoff.** The automatic tick waits five minutes
  before retrying a folder whose key was refused, so a bad key doesn't hammer FlightDesk. The
  person pressing *Poll now* in Settings → Integrations has just fixed that key and wants to see
  it confirmed, so the button (and `POST /api/v1/integrations/flightdesk/poll`) now polls
  regardless.
- Runbook: the fleet role binds a folder on Qalatra's side; FlightDesk's own binding is created
  *as the agent* with `flightdesk agent-bind` run from inside the folder. Without it FlightDesk
  refuses dispatches with "Choose a connected agent".
